# Roadmap - Machine Learning
Este é um repositório de um roadmap voltado para auxiliar pessoas que querem ingressar na área de Machine Learning, sendo uma iniciativa do time Visão da Universidade de Pernambuco, podendo ser de utilidade para qualquer pessoa que queira dominar os fundamentos de Machine Learning, ou buscar algum material para estudo.


::: tip
[Eu](https://github.com/luisfteixeira11) tenho alguns livros dos citados durante o Roadmap, se tiver interesse é só entrar em contato.
:::

::: info
O Roadmap é focado na linguagem de programação Python, então os conteúdos que iremos sugerir serão majoritáriamente focados em Python, sinta-se livre para buscar mais contéudos em linguagens como R, Júlia, Java e Scala.
:::

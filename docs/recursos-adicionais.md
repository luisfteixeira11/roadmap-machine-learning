# Recursos adicionais

 - [Kaggle](https://www.kaggle.com/), uma das grandes comunidades de Machine Learning.
 - [Google Colab](https://colab.google/), muito útil para o desenvolvimento dos modelos.
 - [Jupyter](https://jupyter.org/), o site com os jupyter notebooks e jupyterLab, a própria IDE da Jupyter.
 - [PyPI (Python Package Index)](https://pypi.org/), onde você pode instalar qualquer pacote de Python para utilizar em seus projetos.
 - [Guia do Aprendizado de Máquina - IBM](https://www.ibm.com/br-pt/think/machine-learning#605511093), lugar por onde eu estudei bastante, foi um dos melhores sites para conseguir aprender o essencial.
 - [Stack Overflow](https://stackoverflow.com/questions), local essencial para tirar dúvidas, buscar resoluções, problemas e discutir.
 - [Google Dataset Search](https://datasetsearch.research.google.com/), contém vários datasets para você buscar o dataset que se adeque ao problema do seu modelo mais facilmente.
 - [Udemy](https://www.udemy.com/courses/search/?src=ukw&q=machine+learning), possui vários cursos de Machine Learning que é possível aprender a teoria e prática até os temas mais avançados.
 - [Discussão Kaggle sobre modelos híbridos](https://www.kaggle.com/discussions/general/545962).
 - [Revista focada em pesquisa em Aprendizado de máquina](https://www.jmlr.org/).
 - [Playlist Andrew Ng - Machine Learning Specialization (do Youtube)](https://youtu.be/vStJoetOxJg?si=QqPouxckIPacO8ni)
 - [Playlist Machine Learning - IMPA - Paulo Orenstein](https://youtube.com/playlist?list=PLo4jXE-LdDTRLGDL59SkkLPBHVmYphuqI&si=dy2DYmtZ8izWG94O)

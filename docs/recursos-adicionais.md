# Recursos adicionais

 - [Kaggle](https://www.kaggle.com/), uma das grandes comunidades de Machine Learning.
 - [Google Colab](https://colab.google/), muito útil para o desenvolvimento dos modelos.
 - [Jupyter](https://jupyter.org/), o site com os jupyter notebooks e jupyterLab, a própria IDE da Jupyter.
 - [PyPI (Python Package Index)](https://pypi.org/), onde você pode instalar qualquer pacote de Python para utilizar em seus projetos.
 - [Guia do Aprendizado de Máquina - IBM](https://www.ibm.com/br-pt/think/machine-learning#605511093), lugar por onde eu bastante estudei, foi um dos melhores sites para aprender o essencial.
 - [Stack Overflow](https://stackoverflow.com/questions), local essencial para tirar dúvidas, buscar resoluções, problemas e discutir.
 - [Google Dataset Search](https://datasetsearch.research.google.com/), contém vários datasets para você buscar o dataset que se adeque ao problema do seu modelo mais facilmente.
